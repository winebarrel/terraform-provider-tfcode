# AGENTS.md

A Terraform provider with one data source, `tfcode`, which reads static values
from the `.tf` files of another directory without using its state.

## Layout

```
main.go                     provider server
internal/tfcode/            parsing and evaluation
internal/provider/          the provider, the data source, cty to framework conversion
templates/                  source for docs/
examples/                   examples embedded in docs/
tools/                      go:generate entry point for tfplugindocs
```

`docs/` is generated by `make docs`. Edit `templates/`, `examples/` or the schema
in `internal/provider/`, not the output.

## How evaluation works

While evaluating, an undetermined value is a cty unknown. This is the central
design choice: functions already handle unknowns correctly, so `lookup`, `merge`
and `try` cannot turn an undetermined value into a plausible wrong answer. The
unknowns are removed at the end, in `export`, so a reference to one fails with
Terraform's `Unsupported attribute`.

`evaluator.scope` decides whether an expression can be evaluated at all. A
resource argument the source does not set is absent rather than unknown, so
`try(aws_vpc.main.id, "x")` would answer `"x"` if this check did not reject it.

## Commands

```console
$ make test    # unit and acceptance tests
$ make lint    # golangci-lint
$ make docs    # regenerate docs/
```

The acceptance tests run real Terraform, so the CLI has to be on PATH. They serve
the provider from the test process, so a relative `source` resolves against
`internal/provider/`. Under a real `terraform` run it resolves against the
directory Terraform runs in.

## Conventions

Comments and documentation are in English. Say what the code does and why a
non-obvious choice was made, not what a reader can see from the line itself.
